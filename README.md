# React Portfolio

Pages: Home (`#/`), About (`#/about`), Projects (`#/projects`), Contact (`#/contact`).

1. `npm install`
2. `npm run dev` (opens at http://localhost:5173)
3. Edit `src/data.js` with your name, email, GitHub, skills, projects and the "What I do" text.
4. `npm run build` creates the `dist` folder to deploy (Netlify, Vercel, GitHub Pages).

Pages use hash links (`#/about`), so they work on any host with no extra server setup.
